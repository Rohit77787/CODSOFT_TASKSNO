# Task 4: To-Do List Application

## Description
A menu-driven To-Do List application developed using C++ as part of the CODSOFT C++ Programming Internship.

The application allows users to manage daily tasks efficiently.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Display task status (Completed or Pending)
- Menu-driven interface

## Concepts Used
- C++ structures
- Vectors
- Strings
- Functions
- Loops
- Conditional statements
- User input and output

## How to Run

Compile the program:

`g++ main.cpp -o todo.exe`

Run on Windows:

`.\todo.exe`
