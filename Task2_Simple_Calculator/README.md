# Task 2: Simple Calculator

## Description
This project is a simple calculator developed using C++ as part of the CODSOFT C++ Programming Internship.

The program performs basic arithmetic operations on two numbers.

## Features
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Handles division by zero
- Allows repeated calculations
- Validates numeric input

## Concepts Used
- C++ basics
- Variables and data types
- Conditional statements (`switch`)
- Loops (`do-while`)
- User input and output
- Basic input validation

## How to Run

1. Compile the program:

   `g++ main.cpp -o calculator.exe`

2. Run the program on Windows:

   `.\calculator.exe`
