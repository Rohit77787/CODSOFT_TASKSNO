# Task 3: Tic-Tac-Toe Game

## Description
This is a two-player Tic-Tac-Toe game developed using C++ as part of the CODSOFT C++ Programming Internship.

Players take turns marking the board with X and O. The game detects a winner or a draw.

## Features
- Two-player gameplay
- 3×3 game board
- Win detection for rows, columns, and diagonals
- Draw detection
- Invalid input handling
- Prevents players from selecting occupied positions

## Concepts Used
- C++ functions
- Two-dimensional arrays
- Loops
- Conditional statements
- User input and output
- Game logic

## How to Run

Compile the program:

`g++ main.cpp -o tictactoe.exe`

Run on Windows:

`.\tictactoe.exe`
